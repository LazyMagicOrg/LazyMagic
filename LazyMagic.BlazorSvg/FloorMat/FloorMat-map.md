## Overview

The FloorMat directory contains a **unified pipeline** for generating, extracting, and embedding precomputed geometric layout data for SVG floor plans. After extensive cleanup, the directory has been reduced from ~55 files to **14 essential files** - an **81% reduction**.

### Three Layout Systems

The pipeline supports three parallel layout algorithms:
1. **MaxInscribed** - Largest possible rectangles with no constraints
2. **Boardroom** - Fixed 13ft width, variable length tables
3. **Hollow Square** - Perimeter table arrangements with 4ft+ inner clearance

## Unified Pipeline Workflow

### Full Pipeline (All 251 Combinations)

```bash
# Step 1: Run all tests (generates ../TestResults/*/*.json)
npm run test:all
# Or individually:
npm run test:maxinscribed
npm run test:boardroom
npm run test:hollowsquare

# Step 2: Extract precomputed data (generates precomputed-*.json)
npm run extract

# Step 3: Embed into SVG (updates Level1.svg)
npm run embed

# Or run entire pipeline:
npm run pipeline
```

### Quick Pipeline (Sample Tests)

```bash
# Runs sample tests for all three algorithms
npm run test:samples

# Then extract and embed
npm run extract
npm run embed

# Or quick pipeline:
npm run pipeline:quick
```

## Key Features

### Unified Configuration

All test configuration is now in clean JSON files (`test-configs/*.json`) instead of hardcoded JavaScript.

**Example config structure:**
```json
{
  "testName": "Boardroom Full Tests",
  "algorithm": "boardroom",
  "svgPath": "../../BlazorTest.WASM/wwwroot/Level1-normal.svg",
  "outputDir": "../TestResults/BoardroomResults",
  "algorithmOptions": { ... },
  "combinationsFile": "../valid-combinations.json",
  "outputOptions": { ... }
}
```

### Sample vs Full Tests

- **Full Tests**: All 251 combinations (~60 minutes)
- **Sample Tests**: ~16 combinations (~3-5 minutes)
- Sample tests use separate combination files to run quickly for validation

### Three Datasets in One SVG

The `embed-all-in-svg.js` script embeds all three layout types simultaneously:
```xml
<svg>
  <defs>
    <script type="application/json" id="precomputed-rectangles"><![CDATA[...]]></script>
    <script type="application/json" id="precomputed-boardroom"><![CDATA[...]]></script>
    <script type="application/json" id="precomputed-hollowsquare"><![CDATA[...]]></script>
  </defs>
  <!-- SVG content -->
</svg>
```
